CURE proje bilgi notu
======================

Bu dosya mevcut repo yapisini ozetler. Ayrintili kurulum ve API bilgileri icin
README.md ve docs/features/ altindaki feature dokumanlari esas alinmalidir.

Guncel klasor yapisi
--------------------

- ai_core/: LangGraph/LangChain tabanli Critic-Healer ajan akisi, RAG yardimcisi
  ve log analiz araci.
- backend/: FastAPI endpointleri, parser, OCL validator, renderer, performans ve
  hata log modulleri.
- frontend/: React + Vite tabanli kullanici arayuzu.
- data_pipeline/: Dataset, preprocessing, vector DB hazirligi ve manuel review
  dosyalari.
- docs/features/: Her ana modul ve ozellik icin feature dokumantasyonu.
- experiments/: Autonomous repair deneylerini kosan scriptler.
- results/: Deney scriptlerinin tekrar uretilebilir CSV/JSON ciktilari icin
  ayrilan klasor. Uretilen dosyalar .gitignore ile takip disi tutulur.

Tek tusla calistirma
--------------------

docker-compose.yml backend ve frontend servislerini birlikte ayaga kaldiracak
sekilde doldurulmustur:

    docker compose up --build

Gizli bilgiler
--------------

Gercek API anahtarlari repoya eklenmemelidir. AI ajan ayarlari icin
ai_core/.env.example dosyasi ornek alinip ai_core/.env olusturulabilir.

Deney tekrarlanabilirligi
-------------------------

Autonomous repair senaryolari su komutla calistirilir:

    python experiments/run_autonomous_repair.py --max-iterasyon 3

Sonuclar results/autonomous_repair_results.csv ve
results/autonomous_repair_results.json olarak uretilir. Ozet analiz:

    python ai_core/log_analiz.py results/autonomous_repair_results.json
